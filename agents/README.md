# Agent Configuration (Single Source of Truth)

This folder is the **single source of truth** for the skills, rules, workflows, guides and
troubleshooting knowledge base used by all coding agents supported by APC.

The hidden folders (`.claude/`, `.kilocode/`) contain **only pointers** to these
files, generated by `scripts/sync-agent-pointers.sh|.ps1` from `scripts/agent-homes.json`.

## Structure

```
agents/
├── rules/                  # System constraints (loaded at session start)
│   ├── agent.md            # Master Dispatcher: FIRST RUN GATE, phase gating, OS protocol
│   ├── file-naming-conventions.md
│   ├── gin-integration.md        # FigBug/Gin submodule: limitations + usage protocol
│   ├── jive-integration.md       # ImJimmi/JIVE submodule: JUCE 9 patch + usage protocol
│   └── juce-build-protocols.md   # JUCE 9 = _tools/JUCE submodule via APC_TOOLS_DIR
├── skills/                 # 12 skills with YAML frontmatter (name == folder name)
├── workflows/              # Phase orchestrations (/dream /plan /design /impl /test /ship ...)
├── guides/                 # Reference documentation (state management, documentation system)
└── troubleshooting/        # Self-learning knowledge base
    ├── known-issues.yaml   # 14 known issues
    └── resolutions/        # Resolution documents
```

## How agents load them

| Agent | Rules | Skills | Workflows |
|---|---|---|---|
| Claude Code | `CLAUDE.md` → `@agents/rules/*.md` | `.claude/skills/<n>/SKILL.md` (pointer) | `.claude/workflows/*.md` (pointer) |
| opencode | `AGENTS.md` + `instructions[]` in `opencode.jsonc` | `.claude/skills/` (native pointer discovery) | `.opencode/commands/*.md` (`/status` `/resume` `/new`) + stock `plan`/`build` agent |
| Kilo Code | `.kilocode/rules/*.md` (pointer) | `.kilocode/skills/<n>/SKILL.md` (pointer) | `.kilocode/workflows/*.md` (pointer) |

## Adding a new skill

1. Create `agents/skills/<name>/SKILL.md` with frontmatter:
   ```yaml
   ---
   name: <name>          # MUST match the folder name (kebab-case)
   description: "..."    # 1-1024 chars, include the trigger terms
   ---
   ```
2. Update the index `agents/skills/README.md`
3. Re-run `bash scripts/sync-agent-pointers.sh` to regenerate the pointers
4. Verify with `bash scripts/validate-agent-config.sh`

## Adding a new agent home (e.g. `.cursor/`, `.windsurf/`)

1. Add an entry to `scripts/agent-homes.json` declaring that tool's discovery paths for rules/skills/workflows
2. Extend `scripts/sync-agent-pointers.sh|.ps1` if the tool requires a different pointer format
3. Re-run the sync and the validation

## Conventions

- **JUCE**: the project uses **JUCE 9** from the submodule `_tools/JUCE`, resolved via
  `APC_TOOLS_DIR` (key `tools_dir` in `~/.config/apc/config.json`). Do not use `~/JUCE`.
- **Platforms**: every command in the rules/workflows has a Bash (macOS/Linux) and a
  PowerShell (Windows) version. Never mix shells.
- **Troubleshooting**: always check `agents/troubleshooting/known-issues.yaml` first;
  auto-capture after 3 failed attempts (see `rules/agent.md`).
- The JUCE 8 documents in `troubleshooting/resolutions/` are historical (HISTORICAL banner).
